# Manim Teaching Flow

Use this skill when the code agent must turn a request or teaching plan into classroom-like animation behavior.

- Use a reverse-knowledge-tree mindset: ask what prerequisite intuition must be clear before the target idea.
- Choose the opening beat that fits the lesson: question, concrete example, visual phenomenon, result preview, direct explanation, or task read-in.
- Do not force every lesson into a reusable question-first loop.
- Build from opening structure to mechanism to takeaway.
- Couple important formulas with visible objects, graphs, relations, state changes, or examples.
- Make the animation do the logical work when a section is routed to Manim.
- Use references only when their condition matches this run:
  - `references/generate-pedagogy.md` for generation-time pedagogical design and opening architecture.
  - `references/teacher-script.md` for broad teaching-plan execution.
  - `references/reveal-narration.md` for progressive reveal and subtitle pacing.
