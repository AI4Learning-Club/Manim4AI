# Remotion

Use Remotion as a first-class teaching renderer, not only as packaging.

- Prefer it for concept explanation, framing, transitions, and polished visual rhythm.
- Keep text punchy, scannable, and sequenced.
- Use contrast, spacing, and motion hierarchy to guide attention.
- Make cards feel like part of the lesson, not filler between Manim segments.
- Use Remotion when the section is best served by typography, panels, bullets, icons, or comparison cards.
