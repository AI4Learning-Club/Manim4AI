# Manim Annotation Patterns

Use this skill when the lesson needs local marks that point, label, connect, or emphasize.

- Add annotations only when they clarify the current beat.
- Anchor arrows, labels, highlights, and braces to real objects or coordinate systems.
- Keep long explanation text in layout blocks, not as local overlays.
